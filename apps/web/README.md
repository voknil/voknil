# Voknil Web

Веб-приложение на Next.js для проекта Voknil.

## Разработка

```bash
npm run dev
```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000)

## Сборка

```bash
npm run build
npm start
```

## Docker

```bash
docker build -t voknil-web .
docker run -p 3000:3000 voknil-web
```
